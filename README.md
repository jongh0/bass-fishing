# 🎣 배스 택티컬 시뮬레이터

🌐 **웹 애플리케이션 바로가기**: [https://jongh0.github.io/bass-fishing/](https://jongh0.github.io/bass-fishing/)

스마트폰(모바일)과 PC 어디서나 **실시간 GPS 위치 · 기상청 기상 · 기압 · 한국농어촌공사(RAWRIS) 실시간 저수지 수위**를 연동하여 오늘의 배스 움직임을 예측하고, 상황별 최적의 배스 루어(19종)와 수중 운용 액션을 시뮬레이션할 수 있는 올인원 배스 낚시 웹앱입니다.

---

## ✨ 핵심 기능

### 1. 📍 내 현재 위치 & 전국 503개 농어촌공사(RAWRIS) 실시간 수위 연동
- **최근접 저수지 자동 매칭**: `📍 내 현재 위치` 선택 시, Haversine 대원거리 공식을 통해 전국 낚시 가능한 주요 저수지/담수호(총저수량 1,000천㎥ 이상 503개소) 중 **가장 가까운 농어촌공사 수위 관측소를 자동으로 탐색**하고 실시간 수위 및 거리를 표시합니다. (50km 초과 시 이격 안내)
- **대표 필드 프리셋**: 경기 용인 이동저수지, 안성 고삼·미산저수지, 평택호, 충남 아산호, 삽교호, 대호만, 예당호, 탑정호, 부사호, 전남 장성호, 담양호, 나주호, 대청호, 안동호, 합천호 등 주요 필드 원클릭 선택을 지원합니다.
- **최근 선택 필드 자동 기억**: PC와 모바일 브라우저의 `localStorage`를 통해 마지막 출조 포인트를 자동 기억하며, 저장된 설정이 없을 때는 기본값으로 `📍 내 현재 위치`를 자동 선택합니다.

### 2. 🌊 실시간 저수지 수위·오름수위 전술 분석 & 취수탑 그래픽
- **오름수위 / 내림수위(배수기) 자동 판별**: 전일 대비 수위(EL.m), 저수율(%), 평년 대비 저수율, 실시간 방류량을 종합 분석하여 연안 육초대 오름수위 찬스 및 배수기 대응 전술을 제시하고 배스 활성도 지수에 즉시 반영합니다.
- **취수탑 그래픽 & 원본 그래프**: 만수위/현재수위/사수위를 시각화한 커스텀 취수탑 그래픽 뷰와 한국농어촌공사 실시간 계측 그래프(iframe) 전환 뷰를 제공합니다.

### 3. ⛅ 실시간 기상 · 기압 추이 & 배스 활성도 지수 (Bite Index)
- **Open-Meteo 실시간 기상청 데이터 연동**: 현재 기온, 체감온도, 풍속/풍향, 날씨 상태, 해면기압(hPa), 최근 3시간 기압 변화 추이, 일출·일몰 시각을 실시간 조회합니다.
- **Bite Index 분석 엔진**: 기압 급변동(저기압 접근 시 부레 안정 및 중층 부상 vs 고기압 시 바닥 은신), 음력 월령(사리/보름·그믐 물때), 조도, 수온, 오름/내림 수위 보정을 결합해 실시간 입질 지수(0~100)와 맞춤 전술 브리핑을 제공합니다.
- **실시간 데이터 동기화**: `⚡ 실시간 기상·수위 반영` 클릭 시 현장 환경 변수가 사계절 택티컬 시뮬레이터에 즉시 동기화됩니다.

### 4. 🎯 19종 배스 루어 매칭 엔진 & 2D 수중 액션 시뮬레이터
- **19종 핵심 채비**:
  - **하드베이트 (7종)**: 탑워터 펜슬베이트, 포퍼, 쉘로우 크랭크베이트, 딥 크랭크베이트, 서스펜딩 미노우, 바이브레이션(리플리스), 메탈지그
  - **와이어베이트 (3종)**: 스피너베이트, 버즈베이트, 채터베이트
  - **소프트베이트 (9종)**: 텍사스 리그, 프리리그, 다운샷(드롭샷), 네꼬리그, 와키리그, 노싱커/버징, 캐롤라이나 리그, 지그헤드, 스몰 러버지그
- **정밀 평가 지표**: 계절, 시간대, 수온, 풍속, 물색(맑음/보통/탁수), 커버 구조(석축/수초/수몰나무/자갈사면/브레이크라인/딥채널)를 바탕으로 루어 적합도 점수와 공략 수심층, 추천 액션법을 산출합니다.
- **수중 액션 2D 캔버스**: 루어별 특유의 수중 유영 궤적(워킹더독, 워블링, 저킹, 바텀 범핑, 리프트앤폴 등)을 실시간 캔버스 애니메이션으로 구현했습니다.

### 5. 📘 현장 실전 치트시트 & 장비 환산표
- **물색별 추천 컬러 가이드**: 맑은물(내추럴/고스트), 일반(그린펌킨/워터멜론), 흙탕물/탁수(블랙블루/차트루즈) 시각적 스와치 제공
- **바늘(훅) & 소프트베이트 매칭표**: 웜 크기별 권장 와이드갭 훅, 스트레이트 훅, 웨이티드 훅 호수 가이드
- **싱커 무게 환산표**: 온스(oz) ↔ 그램(g) ↔ 호수 즉시 대조표
- **사계절 수온 구간별 배스 생태 사전**: 4°C 미만 극저수온기부터 28°C 이상 고수온기까지 수온대별 배스 포지션 및 전략 가이드

## 🛠 기술 스택

- **Frontend**: Vanilla HTML5, CSS3 (모바일 퍼스트 반응형 레이아웃), Modern JavaScript (ES2022)
- **Graphics**: HTML5 2D Canvas API (수중 액션 물리 궤적 시뮬레이션)
- **External APIs**:
  - [Open-Meteo API](https://open-meteo.com/): 실시간 기온, 기압, 풍향/풍속, 일출·일몰 데이터
  - 한국농어촌공사 [RAWRIS WRMS](https://rawris-am.ekr.or.kr/): 전국 주요 503개 저수지 실시간 수위, 저수율, 평년 저수율, 방류량
- **Automation & Deployment**: GitHub Actions (주기적 수위 스냅샷 동기화 및 Pages 자동 배포)
- **PWA**: Web App Manifest 지원 (스마트폰 홈 화면 바로가기 추가 지원)
