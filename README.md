# 🎣 배스 택티컬 프로 v3.0 — 사계절 & 실시간 기상 연동 배스 루어 시뮬레이터

🌐 **웹페이지 바로가기 (GitHub Pages)**: [https://jongh0.github.io/bass-fishing/](https://jongh0.github.io/bass-fishing/)

스마트폰(모바일)과 PC 어디서나 실시간 위치·날씨·기압·수온을 반영하여 최적의 배스 루어(19종)와 수중 액션을 시뮬레이션할 수 있는 올인원 택티컬 웹앱입니다.

---

## ✨ 주요 기능

1. **📡 실시간 GPS 위치 & 국내 12대 배스 필드 기상·기압 자동 연동 (`Open-Meteo API`)**
   - 내 현재 위치(GPS) 또는 국내 대표 배스 포인트(예당호, 대청호, 안동호, 합천호, 평택호, 아산호, 대호만, 장성호, 나주호, 충주호, 낙동강, 금강) 선택 시 **현재 기온, 풍속/풍향, 해면기압(hPa) 및 3시간 기압 변화 추이, 일출·일몰 시각**을 실시간으로 가져옵니다.
   - `⚡ 실시간 날씨·수온 시뮬레이터 자동 반영` 클릭 시 계절, 시간대(새벽·해질녘 골든타임/한낮/야간), 추정 수온, 바람 상태가 시뮬레이터에 즉시 동기화됩니다.
2. **🔥 실시간 배스 활성도 지수 (Bite Index) & 기압·월령 브리핑**
   - 최근 3시간 기압 변화량(저기압 접근 시 부레 안정 및 중층 부상 vs 고기압 급상승 시 바닥 은신), 음력 월령(사리/보름달·그믐 대물 찬스), 조도, 수온을 종합하여 오늘의 입질 지수를 계산합니다.
3. **🌊 19종 루어(하드 7 · 와이어 3 · 소프트 9) 매칭 & 2D 수중 액션 시뮬레이션**
   - 계절, 출조 시간대, 수온, 바람, **물색(맑음/보통/탁수)**, 지형(수초/석축/수몰나무/딥채널), **BFS 피네스 모드**에 따른 실시간 매칭 랭킹과 수중 루어 궤적을 애니메이션으로 시각화합니다.
4. **📘 현장 실전 치트시트 (컬러 · 바늘 · 싱커 환산표 · 수온별 패턴)**
   - 물색별 추천 루어/웜 컬러 스와치, 채비별 권장 훅 호수, 온스(oz) ↔ 그램(g) 싱커 무게 환산표, 사계절 수온 구간별 배스 포지션 사전을 제공합니다.
5. **📓 나만의 현장 조행 기록장 (LocalStorage)**
   - 현장에서 히트한 루어와 사이즈를 기록하면 당시의 기온, 추정 수온, 기압, 풍속, 포인트 위치가 함께 스마트폰에 저장됩니다.
